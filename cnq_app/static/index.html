Data format & requirements

One row per subject, with a header row and no blank rows.

ColumnWhat it isExample
Follow-up timeTime until the event or last contact (a positive number)12.4
Event indicator1 = event happened, 0 = censored (still event-free)1
CovariatesOne or more numeric predictorsage = 58
Subject ID (optional)A label for each subject; not used as a predictorS001
  • No blank cells in the columns you use.
  • One row per subject (unique IDs if you provide an ID column).
  • A single header row at the top.
  • Times are positive; the event column is 0 or 1.

Example

subject_id,time,event,age,biomarker,treatment
S001,12.4,1,58,2.7,1
S002,36.0,0,64,1.2,0

Rough guide: aim for at least ~100 events; more events give steadier results.
